## 🚀 CÓMO USAR ESTE PROYECTO

### Opción 1: EJECUCIÓN INMEDIATA (recomendado)
```powershell
# Solo necesitas:
# 1. MySQL corriendo (XAMPP)
# 2. Crear BD ejecutando scripts/schema.sql
# 3. Ejecutar el JAR:

java -jar target\Arquealia-0.0.1-SNAPSHOT.jar

# ¡Listo! La aplicación se abre en 5 segundos
```

### Opción 2: COMPILACIÓN DESDE CÓDIGO
```powershell
# Si quieres compilar desde código fuente:

.\mvnw.cmd -DskipTests package
java -jar target\Arquealia-0.0.1-SNAPSHOT.jar
```

### Opción 3: DESARROLLO/PERSONALIZACIÓN
```
- Abre con tu IDE favorito (IntelliJ, Eclipse, VS Code)
- Estructura Maven estándar → importación automática
- Modifica, compila, ejecuta como cualquier proyecto Maven
```
